# Progressive Visual Exchange (PVE)

**Progressive Visual Exchange** treats successive representations as conversational turns that advance a shared state. Images are the current practical testbed and implementation.

The protocol is an early exploration of progressive exchange of perceptual representations. It is designed to be useful today with existing generative tools and may remain relevant for future higher-bandwidth or non-linguistic channels (including potential sensory or neural interfaces), without depending on their existence.

## Core Idea
Each contribution in a sequence:
- Preserves recognizable continuity with the prior state
- Introduces a clear next action, change, or response
- Functions as a reply that moves the shared interaction forward

This is analogous to spoken turn-taking. The same pattern can, in principle, apply beyond images.
