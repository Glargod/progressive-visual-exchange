# Progressive Visual Exchange (PVE)

**Progressive Visual Exchange** treats successive images as conversational turns that advance, modify, or respond to a shared visual state—rather than generating isolated or merely thematically related images.

## Core Idea
Each image in a sequence:
- Preserves recognizable continuity with the prior frame (setting, objects, lighting, participants)
- Introduces a clear next action, viewpoint change, addition, or removal
- Functions as a reply that moves the shared scene forward

This is analogous to spoken turn-taking and is immediately testable with current text-to-image and image-to-image models.

Early conceptual stage. The pattern is usable today with existing generative tools. Contributions, experiments, and discussions on continuity metrics, shared representations, evaluation protocols, and interface affordances are welcome.
